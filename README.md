# Pixel Sticker Pack

A little 16x16 pixel art sticker set I made in LibreSprite, in the Red Flag Archive colors. Started as a bonus freebie to bundle with orders, turned into social graphics too.

## The set

- `red-flag` — obviously
- `broken-heart` — the crack took forever at this size
- `text-bubble` — for the "he left me on read" posts
- `star` — for the good days
- `the-eye` — because the signs were always there

Files are in `png-native/` (true 16x16) and `png-preview/` (scaled up with nearest neighbor so they stay crisp — do NOT smooth-scale these). `sprite-sheet.png` has all five in a row. `rfa-palette.gpl` is the palette, imports into LibreSprite or GIMP.

## Rules I keep

- 7 colors max. The second I add an eighth it stops looking like pixel art.
- Everything gets eyeballed at 100% AND at sticker size. The heart looked fine big and like soup small — that's why the crack is chunky now.
